# 레벨 뷰어 (웹 페이지)

1월드부터 2월드까지 모든 맵을 **실제 게임 그림**으로 그리고, 최단 해답을 한 수씩 재생하며,
맵마다 설계 의도·맹점·난이도 지표를 옆에 보여 주는 정적 웹 페이지.
오브젝트별로 어떤 씬·SpriteFrames·그림·효과음을 쓰는지도 한 섹션에 정리돼 있다.

- 주소 (GitHub Pages 켠 뒤): **https://chamwhy.github.io/godotTest/**
- 파일: `docs/index.html`, `docs/viewer/` (app.js · style.css · data.js · res/)
- 생성기: `tools/level_viewer/build.py` (+ 설명 데이터 `tools/level_viewer/descriptions.py`)

## GitHub Pages 켜기 (한 번만)

저장소 Settings → **Pages** → Build and deployment

1. Source: **Deploy from a branch**
2. Branch: **`claude/world2-cocoon-design`**, 폴더 **`/docs`** → Save
3. 1~2분 뒤 위 주소로 열린다. (나중에 main 에 머지하면 Branch 를 `main` / `/docs` 로 바꾸면 된다)

`docs/.nojekyll` 이 있어서 Jekyll 변환 없이 파일을 그대로 내보낸다. 빌드 단계가 없으니 Actions 설정도 필요 없다.

## 갱신

맵 JSON 이나 리소스를 바꾼 뒤:

```bash
python3 tools/level_viewer/build.py     # 1~2초
```

`docs/viewer/data.js` 와 `docs/viewer/res/`(쓰이는 그림만 복사)가 다시 만들어진다. 커밋·푸시하면 페이지에 반영된다.
새 맵/월드를 추가하면 `descriptions.py` 의 `WORLDS` 에 키를 넣고, `DESC` 에 설명을 넣는다(없으면 지도·지표만 나온다).

## 페이지에 있는 것

| 섹션 | 내용 |
|---|---|
| 월드별 난이도 곡선 | 스테이지별 최단 수 막대. 누르면 그 맵으로 이동, 올리면 상태 수·소프트락. "표로 보기"로 숫자 표 |
| 레벨 카드 | 지도(게임과 같은 오토타일·그리기 순서·감정별 플레이어·꺼진 실타래 반투명) + 해답 재생(처음/뒤로/재생/앞으로/끝, 수 칩, ←/→ 키) + 좌표·격자 보기 |
| 설명 | 가르치는 것 / 플레이어가 처음 믿는 것 / 깨닫는 것 / 해답 흐름 / 함정 / 메모 / 근거 문서 |
| 지표 | 최단 수 · 탐색 상태 · 소프트락 % · 사망·낙하 상태 · 필수 감정 · 고치·상자 · 고치를 깰 수 있는 수단 |
| 허브 | 포탈 도달 순서(`hub.py`), **연결 파일이 없는 포탈 경고** |
| 리소스 | 오브젝트별 씬 → SpriteFrames → PNG, 조건별 변형, 스크립트 상속, 효과음, 경로 참조 없는 그림 목록 |

## 리소스 추적에서 새로 확인한 것

- **상시 함정은 가시 그림**(`Element/Trap/trap_1~3.png`, 가시 개수 = 피해량)이다. **고추 그림**(`Element/Chili`)은 **일회성 함정 전용**.
  기존 문서들이 상시 함정을 "고추"라고 불러 왔다 → 01·04·08 문서에 정정 표기.
- 상자 = 노란 바위(`Element/Stone`), 회복 = 쿠키(`Element/Cookie`), 목표 = 실타래(`Element/Clear/wool`), 벽 ma 0 = 회색 바위 2종(무작위).
- **1월드 허브 `01_00`의 포탈 10 (5,2)은 `01_10.json`으로 연결되는데, 이 파일은 어느 브랜치에도 없다.** 밟으면 맵 로드 실패.
- 경로로 참조되는 곳이 없는 그림 17장(`Bg/bg.png`, `Effect/chop1~5.png`, `Portal/Stair/stair_1.png`, UI 메뉴 텍스트 9장, `Tip/tip_move.png`) — 페이지 맨 아래 목록.
