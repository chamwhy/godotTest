# 3·4월드에 무엇을 더할까 — 후보 검토

> 브랜치 `claude/world3-design`
> 입력: 1월드(지형 + 고추 + 벽), 2월드(상자 + 누에고치), 그리고 제시받은 후보 3개
> (양방향 포탈 / 열쇠와 문 / 플레이어 행동마다 움직이는 고블린)

---

## 0. 판정 기준

`docs/02_퍼즐설계_분석.md`에서 뽑아낸 이 게임의 세 기둥으로 잰다.

| 기둥 | 뜻 |
|---|---|
| **상태가 곧 동사** | 체력 = 감정 = 할 수 있는 행동. 피해를 입으면 **무엇을 할 수 있는지**가 바뀐다 |
| **중립적인 수가 없다** | 모든 이동이 공격력을 깎는다 (`공격력 = 원래 공격력 − 이동한 칸수`) |
| **멀리서 작용한다** | 상자 힘 전달, 누에고치 게이트 — 내가 직접 닿지 않은 곳이 바뀐다 |

**좋은 추가 규칙은 규칙 하나를 더하면서 기존 규칙과 곱해지는 것이다.**
규칙 하나를 더해 상호작용 하나만 늘어나면, 배울 건 늘고 재미는 그대로다.
2월드가 10스테이지를 쓰고도 단조롭게 느껴진 이유가 정확히 이것이다 —
상자와 누에고치는 서로는 잘 곱해지는데 **감정 시스템과는 거의 곱해지지 않는다.**

그래서 3월드의 1순위 기준은 하나다. **감정 시스템과 곱해지는가.**

## 1. 고블린 (플레이어 행동마다 움직임) — ★ 3월드로 채택

### 왜 가장 센가

감정 시스템과 **양방향으로** 곱해진다. 지금까지 어떤 요소도 못 한 일이다.

**(가) 내 감정이 고블린을 죽일 수 있는지를 정한다**

`공격력 = 원래 공격력 − 이동한 칸수`가 처음으로 **생사를 가른다.**

| 감정 | 이동 | 공격 | 고블린을 죽이려면 |
|---|---|---|---|
| 평온 (hp 4~6) | 1 | 1 | **제자리에서** 때려야 한다 (1칸 걸으면 공격력 0) |
| 화남 (hp 2~3) | 1 | 2 | 걸어가면서 때릴 수 있다 (1칸 이동 + 1의 힘) |
| 격노 (hp 1) | 2 | 2 | **부딪힌 것만** 죽인다 (2칸 가면 공격력 0) |

시뮬레이터로 확인한 실제 전개:

```
격노(hp1)로 R → 2칸 이동, 남은 공격력 0 → 못 때림
다시    R → 고블린에 막혀 0칸 이동, 남은 공격력 2 → 처치
```

**격노는 가장 빠르지만 가장 무력하다.** 2칸을 다 쓰면 때릴 손이 없다.
이 긴장은 이미 코드에 있었는데, 때릴 "이유"가 없어서 드러나지 않았다.
고블린이 그 이유를 만든다.

**(나) 고블린이 내 감정을 바꾼다**

고블린은 **걸어다니는 고추**다. 1월드의 고추는 "내가 밟기로 선택하는" 자원이었다.
고블린은 **나를 찾아오는** 자원이다.

- 피해를 피해야 할 때도 있고, **일부러 맞아서** 화남·격노로 넘어가야 할 때도 있다
- 벽(ma=2)을 부수려면 공격력 2가 필요한데 지금 평온이라면? **고블린에게 맞으면 된다**
- 이게 1월드 고추의 교훈("체력은 쓰는 자원이다")을 한 단계 올린 형태다

**(다) 시간이 생긴다**

지금까지 모든 퍼즐은 **정적**이었다. 같은 칸은 언제 밟아도 같았다.
순찰 고블린이 있으면 **3턴째엔 안전하고 4턴째엔 치명적인 칸**이 생긴다.
"어디로 갈까"에 "언제 갈까"가 붙는다. 상태공간이 아니라 **스케줄링 문제**가 된다.

**(라) 움직이는 벽 = 격노의 브레이크**

가장 깊은 상호작용이다. 격노는 항상 2칸을 가므로 **좌표 홀짝이 고정**된다
(`docs/02`의 패리티 락). 홀짝을 바꾸는 유일한 수단은 벽·상자·맵끝·회복처럼
**멈춰 세우는 것**이었다. 고블린은 **원하는 턴에 원하는 칸에 생기는 브레이크**다.
적을 패리티 도구로 쓰는 퍼즐은 이 게임에서만 가능하다.

**(마) 기존 요소 전부와 곱해진다 — 전부 검증 완료**

| 조합 | 결과 | 검증 |
|---|---|---|
| 상자 + 고블린 | 상자에 치여 죽는다 (멀리서 작용) | ✓ `상자로 처치` |
| 고추 + 고블린 | 고추를 밟고 죽는다 | ✓ `고추로 처치` |
| 구멍 + 추적형 | 나를 따라오다 빠진다 | ✓ `추적 낙하` |
| 누에고치 + 고블린 | 순회 퍼즐에 움직이는 방해물 | 설계에서 사용 |
| 벽 + 순찰형 | 막히면 방향을 뒤집는다 → 왕복 주기 | ✓ `순찰 반전` |

### 두 종류로 나눈 이유

| | 순찰형 (patrol) | 추적형 (chase) |
|---|---|---|
| 행동 | 바라보는 방향으로 1칸. 막히면 **방향만 뒤집고 그 턴은 쉰다** | 플레이어 쪽으로 1칸. **먼 축 우선, 동률이면 가로** |
| 성격 | 완전히 예측 가능한 **시계** | 내 위치에 반응하는 **거울** |
| 퍼즐 | 타이밍·패리티 | 유도(구멍·고추로 끌어들이기) |

**순찰형이 먼저다.** 완전한 예측 가능성이 이 게임의 전제이기 때문이다
(Into the Breach의 교훈 — 완전정보 + 강제된 트레이드오프).
막혔을 때 "뒤집고 쉰다"로 정한 것도 읽기 쉬움 때문이다. 뒤집고 바로 움직이면
한 턴에 2칸처럼 보여서 플레이어가 주기를 세기 어렵다.

추적형의 축 우선순위도 **고정**이다. 랜덤이 섞이면 퍼즐이 아니라 운이 된다.

### 공통 규칙

- 체력 1. **1 이상 맞으면 죽는다**(누에고치와 같은 판정). 플레이어·상자·고추 모두 가능
- 막는다(`is_block`). 그래서 움직이는 벽이자 브레이크다
- 구멍 위에 멈추면 낙하 (상자·플레이어와 같은 규칙)
- 플레이어가 가려는 칸에 있으면 **때리고 제자리에 선다**(기본 1 피해)
- **누에고치처럼 포탈을 잠그지는 않는다.** 목표가 아니라 장애물이자 도구다.
  게이트로도 만들면 3월드가 "움직이는 누에고치 월드"가 되어 버린다

## 2. 양방향 포탈 — ★ 4월드로 미룸

### 센 이유

**공간 인접성을 깬다.** 그리고 기존 두 시스템과 바로 곱해진다.

- **격노 관성 × 포탈**: 2칸 이동 중 첫 칸이 포탈이면 나머지 1칸은 출구에서 이어서 간다.
  패리티 락을 **공간적으로** 깨는 새 수단이다 (지금은 브레이크밖에 없다)
- **상자 힘 × 포탈**: 상자를 포탈에 밀어넣으면 남은 힘을 갖고 출구에서 튀어나온다.
  "멀리서 작용"의 사거리가 맵 전체로 늘어난다
- 누에고치 순회와도 잘 맞는다 — 순회 경로가 접히면서 암산 난이도가 오른다

### 그런데 왜 4월드인가

1. **고블린보다 감정과 덜 곱해진다.** 포탈은 *위치*를 바꾸고, 고블린은 *능력*을 바꾼다.
   이 게임의 심장은 감정이므로 심장을 먼저 깊게 파는 게 맞다
2. **둘을 같이 넣으면 과하다.** 움직이는 적 + 접힌 공간을 동시에 읽히게 만들기 어렵다
3. **격노 관성 × 포탈은 관성을 충분히 익힌 뒤여야 재미있다.** 3월드가 그 숙달 과정이다
4. 구현 난이도도 높다 — `move_to` 루프 안에서 위치를 갈아끼워야 하고, 되돌리기 상태와
   연출(순간이동 중간 프레임)까지 손봐야 한다. 고블린은 턴 뒤에 한 번 움직이는 쪽이 훨씬 안전하다

## 3. 열쇠와 문 — ✗ 제안대로는 비권장

### 솔직한 평가

**세 후보 중 가장 약하다.** 규칙은 늘지만 상호작용이 늘지 않는다.

1. **누에고치가 이미 같은 일을 한다.** "전부 모으면 출구가 열린다"는 순회 게이트다.
   열쇠와 문은 그 개수를 1로 줄인 **더 단조로운 버전**이다
2. **감정과 전혀 곱해지지 않는다.** 열쇠를 줍는 데 체력·이동력·공격력이 쓰이지 않는다.
   순수 동선 문제이고, 이 게임에서 동선만 묻는 요소는 1월드가 이미 다 했다
3. **중립적인 수를 만든다.** "줍기"는 아무것도 깎지 않는 행동이다.
   두 번째 기둥을 정면으로 거스른다

### 살리려면 — 더 센 변형

열쇠를 **들고 다니는 물건이 아니라 밀어야 하는 물건**으로 바꾸면 전부 해결된다.

> **열쇠 = 특별한 상자. 문 = 열쇠를 밀어 넣어야 하는 칸.**

- 줍기가 없으니 중립적인 수가 사라진다
- 열쇠를 미는 거리 = **내 공격력** → 감정과 직결된다
- 힘이 이동으로 깎이니 "어디서 밀 것인가"가 퍼즐이 된다
- 열쇠가 구멍에 빠지면 **복구 불가** → 소코반식 비가역성이 들어온다
- 여러 열쇠 / 여러 문으로 순서 제약도 만들 수 있다

이러면 꽤 괜찮은데, **2월드 상자 메커니즘의 확장**이지 새 월드의 기둥은 아니다.
**4월드의 보조 요소**(포탈과 함께)나 5월드 후보로 두는 걸 권한다.

| 월드 | 기둥 | 근거 |
|---|---|---|
| 1 | 지형 + 고추 (체력 = 자원) | 완료 |
| 2 | 상자 + 누에고치 (멀리서 작용 / 순회) | 완료 |
| **3** | **고블린 — 움직이는 적** | 감정과 **양방향**으로 곱해진다. 시간 축이 생긴다 |
| **4** | **양방향 포탈 + 밀어야 하는 열쇠** | 공간을 접는다. 격노 관성을 공간적으로 깬다 |
| 5 후보 | 체력을 쓰는 능동 행동 (예: 돌진·자해 점프) | 감정을 **쓰는** 쪽으로 한 걸음 더 |

### 3월드 커리큘럼 방침

2월드의 교훈을 반영해 **가르치는 구간을 짧게** 잡는다.
2월드는 평온 구간에 5스테이지를 썼고(1월드는 2개) 그래서 단조로웠다.

- **3-1 ~ 3-2**: 고블린 기본 2개로 끝낸다 (막는다 / 죽일 수 있다 / 주기가 있다)
- **3-3부터**: 반드시 **기존 요소와 조합**한다. 새 규칙을 혼자 쓰는 스테이지를 더 만들지 않는다
- 필수 감정: 평온 2 → 화남 3 → 격노 5 (2월드는 평온 5 / 화남 3 / 격노 2였다)
- 상태공간 상한을 2월드(1002)보다 확실히 위로 올린다
