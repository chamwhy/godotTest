# 부록 — 월드 2 맵 지도 (자동 생성)

`tools/level_sim/render.py`가 맵 JSON에서 직접 뽑아낸 표다. **손으로 고치지 말 것.**
맵을 수정한 뒤 아래로 다시 생성한다.

```bash
cd godot/05_Data/01_MapData
PYTHONPATH=../../../tools/level_sim python3 ../../../tools/level_sim/render.py 02_*.json
```

> **v2 (리디자인) 기준.** 설계 의도·해답·검증은 `08_2월드_리디자인.md`에 있다.
> v1 맵(02_04~02_10)은 `godot/05_Data/01_MapData/legacy/world2_v1/`로 옮겨졌고 게임에서 로드되지 않는다.
>
> ⚠ `render.py`는 **구멍 위에 떠 있는 누에고치**를 바닥 위 고치와 같은 🟣로 그린다.
> 02_05 (0,1), 02_07 (1,2), 02_10 (4,3)의 고치는 아래가 구멍이다(깨지면 그 칸은 구멍).
> 정확한 구분은 `08_2월드_리디자인.md`의 지도(🟪 = 구멍 위 고치)를 볼 것.

## 기호 요약

| 기호 | 뜻 |
|---|---|
| 🙂 | 플레이어 시작 위치 |
| 🚩 | 목표 포탈 — **멈춰야** 발동. 누에고치가 남아 있으면 비활성(어둡다) |
| 🟣 | 누에고치 — 막는다. 1 이상 맞으면 파괴. **전부 부수면 목표 활성화** |
| 📦 | 상자 — 내 공격력만큼 날아가고, 날아간 거리만큼 힘이 줄어든다 |
| 💚 | 회복 — 체력 +n. 지나가기만 해도 발동 |
| 🔴n | 고추 (상시) — n = 피해량. 몇 번이든 다시 밟힌다 |
| 🟡n | 고추 (일회성) — n = 피해량. 한 번 쓰면 사라진다 |
| 🟧n | 벽 — n = 부수는 데 필요한 공격력 |
| 🧱 | 벽 — 파괴 불가 |
| ⬜ | 바닥 |
| ⬛ | 구멍 — 그 위에서 멈추면 낙하. 지나가는 것은 가능 |
| 🔵n | 월드 포탈 (숫자 = 가는 스테이지, 숫자 없음 = 월드 출구) |
