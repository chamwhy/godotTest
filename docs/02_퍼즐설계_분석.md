# 퍼즐 설계 분석 — 기존 스테이지 학습 · 다른 퍼즐게임 비교 · 교차검증

규칙을 1:1 이식한 시뮬레이터로 기존 9개 스테이지를 **전수 탐색해서 직접 풀었고**,
그 결과로 역산한 설계 규칙을 다시 기존 스테이지에 대입해 교차검증했다.

---

## 1. 기존 월드 1 전수 탐색 결과

| # | 이름 | 최단 | 상태공간 | 사망 | 낙하 | 필수 감정 |
|---|---|---|---|---|---|---|
| 01_01 | moving | 7 | 20 | 0 | 3 | 평온 |
| 01_02 | attack | 5 | 710 | 0 | 0 | 평온 |
| 01_03 | double attack | 13 | 304 | 12 | 40 | 화남 |
| 01_04 | state change | 16 | 148 | 9 | 11 | 화남 |
| 01_05 | double move | 8 | 204 | 16 | 48 | 격노 |
| 01_06 | already | 28 | 194 | 3 | 69 | 격노 |
| 01_07 | pepper | 7 | 30 | 3 | 6 | 격노 |
| 01_08 | heal | 20 | 152 | 12 | 31 | 격노 |
| 01_09 | chess | 23 | 250 | 51 | 57 | 격노 |

**스테이지 이름이 곧 가르치는 메커닉이다.** 이것만으로 커리큘럼이 읽힌다.
moving(이동) → attack(부딪힘=공격) → double attack(공격력 2) → state change(감정 전환)
→ double move(이동력 2) → pepper(고추/누에고치) → heal(회복) → chess(종합).

### 학습한 대표 해답

**`01_02 attack` — 같은 입력을 반복시켜 결과의 차이로 가르친다**
```
R → 한 칸 이동
R → 안 움직임. 벽이 부서짐      ← "아, 부딪히는 게 공격이구나"
R R R → 통과
```
튜토리얼 텍스트가 없다. 다섯 번의 오른쪽 스와이프가 전부다.

**`01_03 double attack` — 고추는 장애물이 아니라 열쇠다**
```
U L L L L(고추 atk3 → 체력 6→3, 화남) R R D D R D D D
```
`ma:2` 벽을 열려면 공격력 2가 필요하고, 공격력 2는 체력 3 이하에서만 나온다.
→ 플레이어의 본능("고추를 피한다")을 정면으로 배신한다.

**`01_04 state change` — 체력 다이얼 맞추기**
```
... D D(6→4) U D(4→2) U ...
```
해답에 `D U D`가 들어 있다. 고추를 밟고, 나갔다가, 다시 밟는다.

**`01_07 pepper` — 시작부터 화남, 그리고 걸으면서 때린다**
```
시작 (2,3) hp=3 화남   ← 시작 칸에 atk3 고추가 깔려 있다
U → (2,2) hp=2
U → (2,1) 누에고치 0/1 [포탈ON]   ← 이동만 했는데 (2,0)의 고치가 부서졌다
```
화남의 "걸으면서 전방 1칸 타격"을 몸으로 가르치는 스테이지. 7수 / 상태 30개로
월드에서 가장 밀도가 높다.

**`01_09 chess` — 순수 체력 산수**
```
6 -2→ 4 +1→ 5 -2→ 3 -2→ 1   (격노 진입)
```
고추가 -2뿐이고 시작이 짝수 6이므로 **회복(+1)을 거치지 않으면 홀수 1에 도달할 수 없다.**
"회복을 먹어야 격노가 된다"는 역설이 산수로 강제된다. 그리고 체크무늬 구멍밭에서
나머지 회복 아이템은 도움이 아니라 **덫**이다(밟으면 이동력이 1로 떨어져 고립).

## 2. 이 게임의 퍼즐 재미는 어디서 오는가 — 다른 퍼즐게임과 비교

사용자가 지적한 핵심은 두 축이다.
(a) 소코반류 "이동에 따른 결과 도출" 사고, (b) 체력 기반 이동/공격으로 탈출 루트 구성.
실제 코드를 보면 그 둘이 **세 개의 기둥**으로 구현되어 있다.

### 기둥 A — 상태가 동사를 바꾼다 (state-as-verb)

같은 "오른쪽 스와이프"가 상태에 따라 완전히 다른 행위가 된다.

| 감정 | "오른쪽"의 의미 |
|---|---|
| 평온 | 한 칸 이동. 막히면 1로 때린다 |
| 화남 | 한 칸 이동 **+ 그 앞을 1로 때린다**. 막히면 2로 때린다 |
| 격노 | 두 칸 이동(구멍 넘기). 1칸에서 막히면 1로 때린다 |

→ 플레이어는 좌표가 아니라 **(좌표, 감정)** 공간에서 계획해야 한다.

**비교 — Baba Is You**: 규칙 자체를 퍼즐 조각으로 쓴다. bsk는 그 경량판이다.
규칙을 재작성하진 않지만 내 상태가 내 동사의 의미를 재정의한다. "아하"의 형태가 같고,
탐색 공간은 훨씬 작아서 모바일 한 손 조작에 맞는다.

**비교 — Into the Breach**: 완전 정보 + 결정론 + 작은 격자. bsk도 완전 정보이고
되돌리기가 무료다. 그래서 재미가 "리스크"에서 올 수 없고 **강제된 트레이드오프**에서
와야 한다. ITB의 교훈은 "모든 자원을 이중 용도로 만들라"인데, bsk의 체력은 이미
목숨 · 공격력 · 이동력 세 역할을 겸한다.

**비교 — HP를 자원으로 쓰는 게임들**: 대부분의 게임에서 HP는 실패 타이머다.
bsk는 그걸 **모드 선택기**로 뒤집었다. 그 결과 **회복이 손실이 된다.**
이 역전이 이 게임의 가장 독창적인 지점이고, `01_09 chess`가 그걸 극단까지 민다.

### 기둥 B — 중립적인 수가 없다 (no neutral move)

화남이면 걸을 때마다 앞을 때리고, 격노면 원하는 칸에 설 수 없다.
"아무 일도 일어나지 않는 이동"이 존재하지 않는다.

**비교 — Stephen's Sausage Roll**: 가장 가까운 친척이다. SSR은 내 몸(포크)이
지나가는 자리를 반드시 굽는다. 원하지 않아도. 그래서 퍼즐이 "내 부작용을
어떻게 설계에 끼워 넣을까"가 된다. bsk의 화남 걸으며 때리기가 정확히 같은 구조다.

> **이게 bsk에서 아직 가장 덜 쓰인 금맥이다.** 현재는 `01_07`만 이 성질을 쓴다.
> 월드 2에서 적극적으로 쓴다(`02_07 walk and hit`, `02_10 silk nest`).

**비교 — Snakebird**: 관성과 낙하, 그리고 "어디서 멈출 수 있나"가 퍼즐의 본질.
bsk 격노의 홀짝 고정 + 구멍이 같은 계열이다. 브레이크(벽/상자/맵 끝/회복)를
찾는 것이 곧 퍼즐이 된다.

### 기둥 C — 원격 작용과 감쇠 (action at a distance)

상자는 내 힘을 받아 대신 움직이고 대신 때린다. 그리고 **거리만큼 힘이 줄어든다.**

```
[나][상자][고치]        → 상자 0칸, 남은 힘 2 → 고치 파괴 ✓
[나][상자][  ][고치]    → 상자 1칸, 남은 힘 1 → 고치 파괴 ✓
[나][상자][  ][  ][고치] → 상자 2칸, 남은 힘 0 → 아무 일 없음 ✗
```

**비교 — Sokoban**: 밀기의 비가역성이 원조의 핵심이다. bsk는 그걸 물려받고
한 겹 더 얹는다 — **밀기 거리가 변수(내 감정)다.** 같은 판이 내 상태에 따라 다르게 풀린다.
그리고 상자가 구멍에 빠지면 영구 소실이라 비가역성이 소코반보다 더 날카롭다.

### 그리고 — 누에고치가 퍼즐의 "형태"를 바꾼다

`clear` 포탈이 누에고치 전멸 전까지 비활성이라는 구조는
소코반의 "모든 상자를 목표 지점에"와 같은 역할을 한다.

- **경로 퍼즐**: A에서 B로 가는 길 찾기 (월드 1의 기본형)
- **순회 퍼즐**: N개 지점을 모두 처리한 뒤 출구로 (누에고치 구조)

순회 퍼즐은 **순서(ordering)** 문제를 만든다. 어떤 고치를 먼저 깨느냐에 따라
길이 막히거나 상자를 잃는다. 난이도를 올리는 가장 값싸고 깊은 방법이다.

## 3. 역산한 레벨 설계 규칙과 교차검증

기존 스테이지에서 규칙을 뽑아내고, 다시 기존 스테이지에 대입해 검증했다.
**두 개가 실제로 깨졌다.**

| 규칙 | 교차검증 결과 |
|---|---|
| **R1** 한 스테이지에 새 메커닉 하나. 스테이지 이름이 그 메커닉 | ✓ 월드 1 9개 전부 일치 |
| **R2** 필수 감정 단계가 데이터로 강제되어야 한다 | ✓ 전수 탐색 확인. 평온2 → 화남2 → 격노5로 단조 상승 |
| **R3** 실패가 도달 가능하고 되돌리기 한 번으로 복구돼야 한다 | ✓ 낙하/사망 경로가 거의 모든 스테이지에 존재 |
| **R4** 열린 바닥을 최소화한다 (넓으면 상태만 부풀고 깊이는 안 늘어난다) | ✗ **`01_02` 위반.** 5수 해답인데 상태 710개로 월드 최대. 5×5가 전부 바닥이라 의미 없는 자유도가 크다 |
| **R5** 길이는 통찰에서 나와야 한다. 이동 왕복으로 늘리면 안 된다 | ✗ **`01_06` 위반.** 28수인데 상태 194개뿐. 해답 추적을 보면 맵 끝까지 걸어갔다 되돌아오는 왕복이 대부분이다 |
| **R6** 배치된 모든 오브젝트가 역할을 가져야 한다 | 절제(ablation) 검증으로 판정 — 단, 한계가 있다(아래) |
| **R7** 작고 밀도 높게. 최단 5~25수 | ✓ `01_07`(7수/30상태)이 모범. 대부분 범위 안 |

### 절제 검증의 한계와 보완

오브젝트를 하나씩 빼서 클리어 가능 여부를 보는 절제 검증은 **"막는 물체"에는 쓸 수 없다.**
누에고치나 상자를 없애면 길이 열려서 "없어도 클리어됨"이 나오는데, 이건 동어반복이다.

그래서 **가해자 추적 검증기**(`verify.py`)를 따로 만들었다.
도달 가능한 모든 전이를 훑어서 각 누에고치가
① 플레이어의 직접 타격으로 죽을 수 있는지 ② 상자를 통해서만 죽는지를 판정한다.
(낙하/사망으로 끝나는 전이의 파괴는 해답에 기여할 수 없으므로 제외한다)

이 검증기가 설계 실수를 두 번 잡아냈다.
- 누에고치 위/아래 칸을 막는 걸 잊어서 "상자 전용"이 아니게 된 맵
- 상자가 목표 포탈에 올라가 **코드 버그로 클리어되는** 배치

## 4. 교차검증에서 나온 가장 중요한 발견 — 난이도 곡선은 톱니다

월드 1의 최단 수를 순서대로 늘어놓으면:

```
 7 →  5 → 13 → 16 →  8 → 28 →  7 → 20 → 23
```

**단조 상승이 아니다.** 01_06(28수) 직후 01_07(7수)로 급락한다.
상태공간도 194 → 30으로 떨어진다.

이건 결함이 아니라 **의도된 호흡**이다. 규칙을 보면:

> **새 메커닉을 가르치는 스테이지는 짧고(5~8수), 그걸 응용하는 스테이지는 길다(13~28수).
> 새 메커닉이 등장할 때마다 길이가 리셋된다.**

| 구간 | 스테이지 | 역할 |
|---|---|---|
| 7, 5 | moving, attack | 교육 (짧게) |
| 13, 16 | double attack, state change | 응용 (길게) |
| 8 | double move | 교육 (짧게) |
| 28 | already | 응용 (아주 길게) |
| 7 | pepper | 교육 (짧게) — 새 오브젝트 등장 |
| 20, 23 | heal, chess | 응용 · 결승 |

→ **월드 2에 단조 상승 커브를 요구하는 것은 작성자 본인의 설계 철학과 모순된다.**
톱니를 유지하면서 **봉우리의 높이(envelope)만 올려야** 한다.
이것이 2월드 난이도 재검토의 기준이 되었다. (`docs/03_2월드_설계.md` 5절)

## 5. 좋은 레벨의 조건 (최종)

1. 목표 도달에 필요한 **감정 상태가 하나로 특정**되고, 그게 데이터로 강제돼야 한다.
2. 그 감정에 도달하는 **체력 산수가 유일하거나 거의 유일**해야 한다.
3. 플레이어의 **첫 본능이 명확히 실패**하고, 그 실패가 즉시 이해돼야 한다.
4. 실패는 되돌리기 한 번으로 복구 가능해야 한다.
5. **열린 바닥을 줄여라.** 자유도는 깊이가 아니다 (R4).
6. **길이는 통찰에서. 왕복으로 늘리지 마라** (R5).
7. 새 메커닉 스테이지는 짧게, 응용 스테이지는 길게 — **톱니를 유지하고 봉우리를 올려라.**
