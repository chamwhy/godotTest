## A. 플레이로 확인해야 할 것 (내 수정분 — 전부 엔진 미실행)

위험도 순. **A-1~A-4까지만 통과하면 "일단 돌아간다"는 확인은 끝난다.**

### A-1. 프로젝트가 에러 없이 열리는가 ⚠ 최우선
파일 9개 + `.uid` 6개를 삭제했다. Godot 에디터 출력 패널에 **빨간 에러가 0건**이어야 한다.
- 지운 것: `main2.tscn`, `main.tscn*.tmp`, `monster.tscn`, `Components/`(4개), `Systems/Save/`, `Test/`
- [ ] 에디터 열고 출력 패널 확인 — `uid://` 못 찾는다는 에러가 뜨면 알려줄 것

### A-2. 타이틀 탭 → HUD가 나타나는가 ⚠
`main.tscn`의 `UI/InGame` 초기 알파를 **1 → 0** 으로 바꿨다.
`GameStarter._start_game()`이 0.3초에 걸쳐 1로 올리는 게 정상 동작(`main.tscn:1346`이 이 노드를 가리킴).
- [ ] 타이틀 화면에서 **HP바·메뉴 버튼이 안 보여야** 한다
- [ ] 화면 탭 → **HP바·메뉴 버튼이 페이드인**돼야 한다
- [ ] ⚠ **탭했는데 HUD가 계속 안 보이면 내 버그다** — 바로 알려줄 것 (알파를 되돌리면 된다)

### A-3. 첫 실행 / 재실행 / 세이브 유지
`wipe = true → false`, `develop = true → false` 로 바꿨다.
- [ ] 세이브 지우고 **첫 실행 → 1-1**로 시작
- [ ] 앱 끄고 **다시 실행 → 0-0(메인 허브)**로 시작
- [ ] 볼륨을 바꾸고 재실행 → **볼륨이 유지**되는가 (전에는 매 실행 초기화됐다)
- [ ] 스테이지를 깨고 재실행 → **클리어 기록이 유지**되는가

### A-4. 빈 칸 공격이 사라졌는가 + 부수 효과 ⚠ 가장 조심
`Unit.attack()`이 때릴 대상(`hitable`)이 없으면 아무 기록도 남기지 않게 했다.
`hitable`은 벽·상자·누에고치·고추가 `true`, **회복 아이템과 포탈이 `false`**다.
- [ ] 1-2 같은 넓은 맵에서 **아무것도 없는 방향으로 스와이프** → 공격음(`attack-1`)과 베기 이펙트가 **안 나야** 한다
- [ ] 같은 상황에서 **되돌리기(더블탭)** → 화면이 그대로인 헛턴이 쌓이지 않아야 한다
- [ ] **벽 / 상자 / 누에고치 공격은 그대로** 소리·이펙트가 나야 한다 (여기서 조용하면 내가 망친 것)
- [ ] ⚠ **의도한 부수 효과**: 이제 **맵 끝이나 회복 아이템 쪽으로 스와이프할 때 캐릭터가 그 방향으로 돌아보지 않는다.**
      `look_right`를 공격 기록과 같이 갱신했기 때문이다. 이게 어색하면 말해줄 것 — 돌아보기만 따로 떼면 된다

### A-5. 낙하 → 되돌리기 → BGM
`Player._undo_anim_falling` → `_anim_undo_falling` (이름이 틀려서 **호출 자체가 안 됐다**).
- [ ] 구멍에 빠진 뒤 되돌리기 → **BGM이 다시 들려야** 한다 (전에는 영구 정지)
- [ ] 낙하·복귀 연출이 **0.4초**로 빨라진 게 과하지 않은가 (1.0초였다. `Element.FALL_DUR`)

### A-6. 메뉴 버튼 터치
`MenuBtn`을 `ui_blocker` 그룹에 넣어 `InputManager._is_over_ui()`를 살렸다.
- [ ] 메뉴 버튼에서 시작해 **드래그 → 캐릭터가 움직이지 않아야** 한다
- [ ] 메뉴 버튼 **더블탭 → 되돌리기가 안 걸려야** 한다
- [ ] 메뉴 버튼은 **여전히 정상 작동**해야 한다 (눌러서 설정창 열림)
- [ ] 설정창이 **열린 상태로** 스와이프 → 캐릭터가 움직이면 **미완**이다 (`HpBar`·`SettingsPanel`은 아직 그룹 미등록 — 06_TODO 1절 참조)

### A-7. 설정창 홈 / 리셋
`await close()` 후 로드하도록 바꾸고, 홈을 **현재 월드 허브**로 바꿨다.
- [ ] **2-7**에서 메뉴 → 홈 → **2월드 허브(02_00)**로 가야 한다 (전에는 00_00으로 가서 뱀길 재주행)
- [ ] 홈·리셋 직후 **입력이 멈추거나 화면이 굳지 않는가** (일시정지가 안 풀리는 레이스를 고친 부분)

### A-8. 세로 고정
`project.godot`에 `orientation=1`(Portrait) 추가.
- [ ] 실기기에서 **눕혀도 화면이 안 돌아가야** 한다

### A-9. 그려지는 순서
`ZIndexer.calc`가 `zid` 인자를 버리고 있던 걸 `y * Y_STRIDE + zid`로 고쳤다. **겹침 순서가 바뀔 수 있다.**
- [ ] 캐릭터가 타일 **위에** 그려지는가
- [ ] 같은 칸의 고추·회복·포탈이 캐릭터를 **덮지 않는가**
- [ ] 베기/고스트 이펙트가 캐릭터에 **가려지지 않는가**

### A-10. 소리와 프레이밍 (들어보고 / 봐야 판단되는 것)
- [ ] **누에고치 파괴음** — `broken_jar`(항아리)를 임시로 붙였다. 2월드 02_01에서 들어보고 **쓸 만한지 / 전용 음원이 필요한지** 판단
- [ ] **게임 시작음** — 없는 키라 `enter_stage`로 임시 대체. 타이틀 탭 때 들어보고 판단
- [ ] **메뉴 선택음** — 없는 키라 `hit-1`(피격음)로 임시 대체. **이건 어색할 가능성이 높다**
- [ ] **1월드 허브(01_00)** — zoom 0.6→0.5, offset 제거. 오른쪽 끝 **2월드 출구 포탈이 다 보이는가** (전엔 반쯤 잘렸다)
- [ ] **2-4** — zoom 0.7→0.9. 너무 꽉 차지 않는가
- [ ] 화면 사용률 **100%인 두 맵(1-6, 2-7)** — 계산상 딱 맞다. 실기기에서 **아슬아슬하게 잘리지 않는가**

### A-11. HP바 / 감정 표시
- [ ] 체력 **1**일 때 프로필이 **격노**인가
- [ ] **죽는 순간** 프로필이 '평온'으로 돌아가지 않는가 (hp 0에서 인덱스 −1 → 배열 마지막이 나오던 버그)
- [ ] **1-7, 1-8**은 시작 칸 고추로 **체력 3(화남)에서 시작**한다 — 의도한 설계인지 확인
      (↑ 정정: 전에 "시작 칸 고추가 사라지지 않는다"고 보고했는데, 이 둘은 **상시 고추**라
      안 사라지는 게 맞다. 내 오진이었다. `settle_spawn_actions()`의 실제 효과는
      스폰 중 쌓인 기록이 첫 턴에 섞여 들어가는 걸 막는 것이다)
- [ ] 그래서 확인할 건 하나: **첫 턴에 되돌리기**를 눌렀을 때 이상하게 동작하지 않는가

## B. 내가 결정해줘야 하는 것 (판단이 필요해 손대지 않음)

답을 주면 바로 코드/레벨로 반영할 수 있는 것들이다.

- [ ] **B-1. 1월드 → 2월드 출구 위치.** 지금 01_00 허브 도달 순서가
      `1,2,3,4,5,6,7,8,10,출구,9`다. 즉 **10번 스테이지 포탈을 지나야 2월드로 갈 수 있다.**
      → ⓐ 의도한 게이트다 / ⓑ 아니다 → 출구를 앞으로 옮기거나 명시적 해금(`is_unlocked`)으로 전환
- [ ] **B-2. 2-2에 누에고치를 넣을까.** 2월드 10개 중 **2-2만 고치가 없어** 목표 포탈이 처음부터 켜져 있다.
      → ⓐ 숨 돌리는 칸으로 의도 / ⓑ 일관성을 위해 1개 추가
- [ ] **B-3. 감정별 BGM을 살릴까.** `tier_2.ogg` / `tier_3.ogg`가 있는데
      **재생하는 코드 경로가 아예 없다**(로드조차 안 됨).
      → ⓐ 복구(감정이 주제인 게임이니 효과 큼) / ⓑ 자산 폐기
- [ ] **B-4. UI 언어.** 확인창이 `"Return to home?"`, `"Reset?"`로 영어뿐이다.
      현재 폰트 `JustMeAgainDownHere`에 **한글 글리프가 없어** 지금 한글화하면 □□□로 깨진다.
      → ⓐ 한글 지원 폰트로 교체 후 전체 한글화 / ⓑ 영어로 통일 (이러면 B-4는 닫힘)
- [ ] **B-5. 2-10을 쪼갤까.** 생존 상태 **851개 / 소프트락 692개(81%)**로 결승전치고도 과하다.
      → ⓐ 맵을 좁힌다 / ⓑ 두 스테이지로 분할 / ⓒ 그대로 두고 되돌리기 버튼(A절 아님, 06_TODO 3절)으로 커버
- [ ] **B-6. `TilePreset`을 살릴까 지울까.** 타입 선언만 되고 쓰이는 곳이 없다(`Tiles.gd:23`, 84행에 TODO).
      기본값 경로 `res://assets/sprites/default_tile.png`는 **없는 파일**이다(실행 영향 없음).
      → ⓐ 타일 프리셋 기능을 쓸 계획이다 / ⓑ 지운다
- [ ] **B-7. 2월드 평온 구간이 길지 않은가.** 2-1~2-5가 5스테이지 연속 평온(1월드는 2개).
      → ⓐ 그대로 / ⓑ 2-05 ↔ 2-06을 교체해 화남을 한 칸 앞당긴다
- [ ] **B-8. 콘텐츠 분량 목표.** 현재 19스테이지 / 최단 합계 약 220수 = 숙련자 **30~60분**.
      무료면 지금도 가능하지만 **유료면 60~80스테이지**가 필요하다. 목표를 정해줘야 3월드 설계 규모가 잡힌다
- [ ] **B-9. 게임 타이틀.** `project.godot`가 아직 `bsk`다
