# QA 리포트 — 첫 실행부터 2월드 클리어까지

## 테스트 방법

실행 바이너리가 없는 환경이라 **코드 경로 추적 + 규칙 시뮬레이터 전수 탐색**으로 검증했다.

- 부팅 경로: `project.godot → main.tscn → GameStarter → InputManager 상태기계 → StageDirector`
- 19개 스테이지 전수 탐색 (`tools/level_sim`)
- 신규 검증기 2종 추가
  - `deadend.py` — **소프트락**(살아 있는데 클리어 불가) 상태를 전수 계산
  - `hub.py` — 허브에서 모든 스테이지에 실제로 도달 가능한지, 강제되는 순서
- 리소스 교차검증: 코드가 요청하는 SFX/텍스처 키 ↔ 실제 파일
- 카메라 줌 ↔ 맵 크기 ↔ 뷰포트(1080 고정폭) 계산

# 3. 개선 됐으면 하는 점

| # | 내용 | 이유 |
|---|---|---|
| I-1 | **되돌리기 버튼을 화면에 상주시킬 것** (가장 중요) | 더블탭은 발견 불가능한 조작인데, 후반 스테이지는 **도달 가능한 생존 상태의 47~81%가 이미 클리어 불가**다(5절). 안전망이 숨겨져 있다 |
| I-2 | **스테이지 리셋 버튼을 HUD에 노출** | 현재 메뉴 → 리셋 → 확인창으로 3단계. 소프트락 빈도를 생각하면 1탭이어야 한다 |
| I-3 | **낙하/사망 연출을 1.0초 → 0.3~0.4초로 단축** | `Element._anim_falling`이 1초, 되돌리기도 1초. 실패-재시도가 핵심 루프인데 왕복 2초는 너무 느리다 |
| I-4 | **현재 스테이지 번호를 HUD에 표시** | 지금은 자기가 몇 번을 하는지 알 수 없다 |
| I-5 | **이동 수 카운터 + 최소 수 기록** | 퍼즐 장르 표준. 재도전 동기와 "내가 잘 풀었나" 피드백을 공짜로 준다 |

# 6. 출시 기준 성공을 위해 손봐야 하는 점

## 6-1. 반드시 (없으면 스토어에 못 올림 / 올려도 1일 이탈)

1. **P0 5건 전부** — 세이브 와이프, 디버그 시작점, 화면 회전, 아이콘/스플래시, 엔딩
2. **S-5(UI 터치 차단), S-6(사망 UI), S-1(BGM 영구 정지)** — 첫 세션에 반드시 마주치는 치명적 결함
3. **I-1/I-2(되돌리기·리셋 버튼)** — 소프트락 47~81%인 게임에 안전망이 숨겨져 있다
4. **S-10(전환 연출)** — 맵이 툭툭 바뀌는 것만으로 "미완성 앱" 인상을 준다

## 6-2. 상업적으로 중요

| 항목 | 현재 | 필요 |
|---|---|---|
| **콘텐츠 분량** | 19스테이지, 최단 합계 약 220수 | 숙련자 기준 30~60분. 유료 앱이면 **최소 60~80스테이지**, 무료면 더 필요 |
| **온보딩** | 팁 2개 중 1개만 작동, 핵심 규칙 설명 패널이 죽어 있음 | m-2/I-6 해결. 감정 시스템은 **반드시** 설명해야 한다 |
| **진행 보상** | 없음 | 스테이지 클리어 연출, 월드 클리어 연출(`clear_world.wav`가 이미 있다), 수집 요소 |
| **재플레이 가치** | 없음 | 최소 수 기록(I-5), 별점, 숨겨진 스테이지 |
| **접근성** | 없음 | 색각 보조(감정을 색으로만 표현 중), 사운드 없이 플레이 가능 여부, 좌/우손 모드 |
| **스토어 대응** | 없음 | 스크린샷, 소개 영상, 설명 문구, 개인정보 처리방침(광고/분석 붙일 경우) |
| **분석/크래시** | 없음 | 어느 스테이지에서 이탈하는지 모르면 밸런싱이 불가능하다. 최소한 스테이지별 시도/클리어/이탈 수집 |

## 6-3. 이 게임의 강점 (지켜야 할 것)

QA 관점에서도 **핵심 설계는 상업성이 있다.**

- "체력이 곧 감정이고 감정이 곧 동사를 바꾼다"는 훅은 한 줄로 설명되고 독창적이다
- 화남의 "걸으면서 때린다"는 Stephen's Sausage Roll류의 깊이를 가진 재료다
- 되돌리기 무료 + 완전 정보 + 결정론 → 모바일 한 손 퍼즐에 정확히 맞는다

따라서 **콘텐츠 분량과 온보딩**이 성패를 가른다. 메커닉은 이미 충분하다.

**현 리스트로는 보장된다 — 단, 아래를 구분해서 읽어야 한다.**

| 3절 (10) + 4절 (10) | **"일반적인 상업 퍼즐 앱의 품질"** ← 루프 조건 충족 지점 |
| 5절 (8 + 소프트락 대응) | 레벨 품질이 메커닉 수준을 따라옴 |

즉 **1~5절을 전부 처리하면 "일반적인 게임 앱 수준"은 확보된다.**
6-2절(특히 콘텐츠 분량 60~80스테이지)은 그 위의 문제이고, 이번 QA 범위를 넘는다.
