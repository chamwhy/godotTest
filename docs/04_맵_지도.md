# 부록 — 맵 지도 (자동 생성)

`tools/level_sim/render.py`가 맵 JSON에서 직접 뽑아낸 표다.
**손으로 고치지 말 것.** 맵을 수정한 뒤 아래 명령으로 다시 생성한다.

```bash
cd godot/05_Data/01_MapData
python3 ../../../tools/level_sim/render.py 01_08.json 01_09.json 02_01.json 02_02.json 03_01.json 03_02.json \
  > ../../../docs/04_맵_지도.md   # 헤더는 다시 붙여야 함
```

## 기호 요약

| 기호 | 뜻 |
|---|---|
| 🙂 | 플레이어 시작 위치 |
| 🚩 | 목표 (클리어 포탈) — **멈춰야** 발동. 지나가면 클리어되지 않는다 |
| 📦 | 상자 — 맞은 힘만큼 날아가고, 날아간 거리만큼 힘이 줄어든다 |
| 💚 | 회복 아이템 — 체력 +1. 지나가기만 해도 발동 |
| 🔴n | 함정 (영구) — n = 피해량. 몇 번이든 다시 밟힌다 |
| 🟡n | 함정 (일회성) — n = 피해량. 한 번 쓰면 사라진다 |
| 🟧n | 부술 수 있는 벽 — n = 필요한 공격력 |
| 🧱 | 벽 — 파괴 불가 |
| ⬜ | 바닥 |
| ⬛ | 구멍 — 그 위에서 멈추면 낙하. 지나가는 것은 가능 |
