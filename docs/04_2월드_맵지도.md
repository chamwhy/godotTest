# 부록 — 월드 2 맵 지도 (자동 생성)

`tools/level_sim/render.py`가 맵 JSON에서 직접 뽑아낸 표다. **손으로 고치지 말 것.**
맵을 수정한 뒤 아래로 다시 생성한다.

```bash
cd godot/05_Data/01_MapData
PYTHONPATH=../../../tools/level_sim python3 ../../../tools/level_sim/render.py 02_*.json
```

> **v4 기준 (2026-10-25).** 누에고치 없이 돌·발판 + 1월드 재료(벽·항아리·기둥·가시·칠리·쿠키·구멍)로 다시 만들었다.
> 설계 의도·해답·검증은 `16_2월드_v4.md`에 있다.
> v3 맵 10개는 `legacy/world2_v3/`, v2는 `legacy/world2_v2/`, v1은 `legacy/world2_v1/`에 있고 게임에서 로드되지 않는다.
>
> 실제 게임 그림으로 보려면 레벨 뷰어(`docs/index.html`, GitHub Pages)를 볼 것.
